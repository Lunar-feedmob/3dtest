# 建筑空间分析报告

依据上传的 250㎡ 住宅户型平面图（图面总尺寸 19800 × 14400mm）建立。
模型坐标系：1 Three.js unit = 1m；原点位于户型西北角（影音室北墙外角），X 轴向东，Z 轴向南；图面"北"为 -Z 方向。

## 一、户型结构分析

- 整体轮廓：主体 19.8m × 12.4m 矩形，南侧（+Z）外挑景观阳台 12.4m × 2.5m，呈 L 形缺口于东南角。
- 南北方向：图面指北针向上，即阳台、客厅、主卧朝南，采光面在南向与北向两条长边。
- 采光方向：南向（阳台落地窗 + 客厅/主卧窗）、北向（影音室/餐厅/厨房/次卧窗带）、东向（次卧2/主卫窗）。
- 动静分区：
  - 动区（西+北）：玄关、客厅、家庭起居厅、餐厅、厨房、多功能影音室、健身房、景观阳台。
  - 静区（东）：主卧套房（主卫+衣帽间）、次卧1、次卧2、书房。
- 公共区域：客厅 32㎡ + 家庭起居厅 22㎡ + 餐厅 16.5㎡ 形成南北通透的三厅格局，中部走廊串联东西。

## 四、3D 建模规划

- 比例：1 unit = 1m；层高 2.9m；外墙厚 0.24m，内墙 0.12m；门洞高 2.1m；窗台 0.9m / 窗楣 2.4m。
- 结构：外墙带北向整条窗带、东/西窗、南阳台栏板（玻璃栏板 1.1m）；客厅-阳台为玻璃移门（一半开启可通行）。
- 地面分区：木地板（厅/卧）、大理石（过道/玄关）、灰砖（厨卫/阳台）、地毯（影音室）。
- 家具：程序化高模（圆角几何 + 分层结构），含沙发坐垫/靠背/扶手、床垫/被/枕/床头灯带、橱柜/水槽/灶/冰箱、淋浴玻璃/浴缸/台盆镜柜。
- 材质：PBR（BaseColor + Roughness + Metalness + 程序化 NormalMap）；木地板/瓷砖/布料/地毯均带法线细节。
- 灯光：Hemisphere + Directional（太阳，2048 软阴影）+ PMREM 环境 + RectAreaLight（客厅/起居厅灯膜、阳台采光面）+ 15 盏 PointLight 夜间筒灯；昼夜切换。
- 后处理：SSAO 环境光遮蔽 + ACES Filmic ToneMapping + PCFSoft 阴影。
- 碰撞：玩家半径 0.3m 圆柱 vs 墙体/家具 AABB（滑动解耦 X/Z），眼高 1.6m，步行 1.5m/s、Shift 2.8m/s。
- 视角：第一人称 / 鸟瞰(Orbit) / 轴测(Ortho+Orbit) / 2D 户型图（canvas 交互图 + 原始图切换，点击房间跳转）。
